# Spotify Playlist Overlap Analyzer
Simple python script that allows you to see the overlap between 2 spotify playlist (with a csv input).

I used *Exportify* to get the csv file of my playlist, but you can edit the code to make it work with any input if you want.

#How to use:
1) Place both csv files on the root of the proyect
2) Change the names of "ARCHIVO_A" and "ARCHIVO_B" on Main.py (OPTIONAL: adjust the matching umbral)
3) run with: python Main.py 
4) Check the output csv file (I highly recommend using a csv viewer like the "csv" exptensión on vscode to visualize easily)
